# 枕边 · 睡眠记录

一个只记录「上床时间」的轻量睡眠 App。打开即对准此刻，上下翻动微调，自动计算平均入睡时间与作息规律。

![枕边桌面端预览](preview.png)

## 打开方式

- **直接打开**：双击 `index.html`。数据保存在当前浏览器的本地存储中。
- **像 App 一样打开（Windows）**：双击 `open-app.cmd`，会用 Edge 的应用窗口打开，不带地址栏。
- **安装为 PWA（可选）**：在本目录启动一个本地服务器，然后用 Edge / Chrome 打开并安装：

  ```powershell
  python -m http.server 4173
  ```

  访问 `http://127.0.0.1:4173/`，在浏览器地址栏右侧选择「安装应用」。用这种方式打开时，离线缓存也会生效。

> `file://` 与 `http://127.0.0.1:4173` 属于不同的浏览器来源，两者的数据不互通。请固定使用一种打开方式。

## 在手机上打开

### 方式一：同一 Wi-Fi 下临时访问（最快）

1. 双击 `start-phone-server.cmd`。
2. 如果 Windows 防火墙询问，勾选「专用网络」并允许访问。
3. 让手机连接与电脑相同的 Wi-Fi。
4. 在手机浏览器打开脚本显示的地址，例如：

   ```text
   http://192.168.10.105:4173/
   ```

电脑需要保持开机，服务器窗口不能关闭。这种方式是局域网 HTTP，**不能完整安装为 PWA、也没有离线缓存**；手机和电脑的数据也彼此独立。如果路由器重新分配了电脑 IP，地址会变化。

### 方式二：部署到 HTTPS 静态网站（推荐长期使用）

`pillow-sleep-app.zip` 已经打包好运行所需的全部文件。把它上传到任意静态网站托管（例如 Netlify Drop、Cloudflare Pages、GitHub Pages、Vercel），得到一个 HTTPS 网址：

1. 手机浏览器打开该网址。
2. iPhone Safari：分享 → **添加到主屏幕**。
3. Android Chrome：菜单 → **安装应用 / 添加到主屏幕**。

HTTPS 方式可以启用离线缓存，安装后像普通 App 一样从桌面打开。手机上记录的数据保存在手机浏览器里，**不会与电脑端自动同步**。

> 不要只把 `index.html` 通过微信发到手机：CSS、JS、图标和本地存储都需要完整目录，手机直接打开本地 HTML 也容易受限。请使用上面的局域网或 HTTPS 方式。

## 核心规则

- **默认就是此刻**：没有已有记录时，时间轮会自动跟随打开 App 的时间；放置超过一分钟后也会跟着走到当前分钟。点击「跟随此刻」可以随时重新对准。
- **翻动式调整**：小时、分钟两列滚轮，支持鼠标滚轮、拖动、触屏滑动和方向键；时间只到分钟。界面中没有时间输入框。
- **睡眠分界点**：默认推荐 **凌晨 05:00**，可精确到分钟。早于分界点入睡，记录归到前一天晚上；例如 10 月 27 日 02:30 入睡，会记在 10 月 26 日这一晚。点击主卡片的「睡眠分界点」或右上角齿轮可修改。
- **平均入睡时间**：按圆周时间计算，跨午夜不会算错。比如 23:50 和 00:10 的平均是 00:00。
- **作息规律度**：根据最近一段时间的入睡时间波动（标准差）给出提示，并显示较前一个周期的提前/推迟。
- **统计范围**：近 7 晚、近 30 晚、全部记录。
- **每一晚**：可修改或删除任意一晚；每一晚只保留一条记录，同晚重复保存会更新原记录。

## 数据

所有记录保存在浏览器的 `localStorage` 中，不会上传到任何服务器。清除浏览器站点数据、换浏览器或换设备都会导致记录不可用。推荐固定使用同一个浏览器与打开方式。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | App 页面 |
| `styles.css` | 视觉样式与响应式布局 |
| `sleep-core.js` | 日期归属、跨午夜平均、周期筛选等纯计算 |
| `app.js` | 时间轮、界面渲染、记录增删改与设置 |
| `manifest.json` / `sw.js` | PWA 安装信息与离线缓存 |
| `assets/` | App 图标 |
| `open-app.cmd` | 用 Edge 应用窗口打开 |
| `start-phone-server.cmd` | 同一 Wi-Fi 下让手机访问 |
| `pillow-sleep-app.zip` | 可直接上传到静态托管的完整包 |
| `tests/sleep-core.test.js` | 时间计算测试 |

## 测试

```powershell
node tests/sleep-core.test.js
```

测试覆盖分界点归属、跨午夜平均、最早/最晚、近 N 晚筛选和日期跨月等情况。
